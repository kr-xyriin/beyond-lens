## ✦ What we're building

Beyond Lens is an **independent, AI-assisted platform** intended to connect prospective college students with current students for firsthand perspectives and meaningful conversations. The aim is to help students and parents ask better questions and make more informed decisions.

> **Current scope:** The root README identifies **Phase A — Frontend foundation** as in progress. Existing screens may contain prototype/demo behavior. Production authentication, booking, payments, and AI services are **not live yet**.

## 🔄 How this documentation stays current

- **Automatic on page load:** GitHub/Shields.io badges show commit activity, contributors, issues, and pull requests.
- **Always-live links:** The activity, issue, and PR pages reflect the repository's latest state.
- **Maintained in commits:** Architecture, phase completion, and decision rationale are **not inferred from commit counts**. Update the relevant Markdown file in the same PR as the corresponding change.
- **Review rule:** Any PR that changes an API, dependency, feature status, setup command, or architectural decision should update its related docs.

> A new commit does **not** necessarily mean a feature is complete. Phase status remains a reviewed, human-maintained statement.
